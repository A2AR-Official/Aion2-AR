# A2AR

<div dir="rtl">

## العربية

**مشغّل A2AR مخصّص لنسخة Steam من لعبة أيون 2. يوفّر تعريبًا جزئيًا للعبة ومساعدًا للاستخدام أثناء اللعب.**

### ماذا يقدم؟

- **تعريب جزئي:** يعرض جزءًا من نصوص اللعبة بالعربية، مع بقاء بعض الأسماء والنصوص بالإنجليزية.
- **مساعد أيون 2:** يعرض إحصاءات الضرر والعلاج أثناء اللعب، ويضم جدولًا لمواعيد الفعاليات في سيرفر **EU**.

### كيف أستخدمه؟

1. [نزّل المثبّت A2AR-Setup.exe](https://github.com/SahorAR/A2AR-AION2/releases/latest/download/A2AR-Setup.exe) وشغّله، ثم اتبع خطوات التثبيت. **يكفي تنزيل هذا الملف فقط.**
2. افتح A2AR وفعّل الميزات التي تريد استخدامها: التعريب أو المساعد أو كليهما.
3. اضغط زر **«تشغيل اللعبة»** في المشغّل.
4. إذا فعّلت التعريب، اضبط لغة اللعبة على **English** قبل الدخول إلى عالم أيون 2.

حتى يظهر المساعد أثناء اللعب، اختر **Windowed Mode** أو **Borderless Window Mode** من إعدادات العرض في اللعبة.

<p dir="rtl">مشروع A2AR مستقل وغير تابع لمطوّر اللعبة.</p>

## English

**A2AR is a launcher for the Steam version of AION 2 that brings a partial Arabic translation and an in-game assistant together in one place.**

### What does it do?

- **Partial Arabic translation:** Displays supported text in Arabic. Some names and text remain in English.
- **AION 2 assistant:** Shows damage and healing while you play, with an event schedule for the **EU server**.

### How do I use it?

1. [Download A2AR-Setup.exe](https://github.com/SahorAR/A2AR-AION2/releases/latest/download/A2AR-Setup.exe), run it, and follow the installation steps. **This is the only file you need to download manually.**
2. Open A2AR and enable the translation or assistant as needed. You can use either feature independently.
3. If you enable the Arabic translation, select **English** as the game's language before entering the world of AION 2.
4. Click the launch button in A2AR to start the game.

To see the assistant in-game, choose **Windowed Mode** or **Borderless Window Mode** in the game's display settings.

A2AR is an independent project and is not affiliated with the game's developer.
